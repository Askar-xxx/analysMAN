## Кратко о проекте
Telegram-бот на Python (python-telegram-bot, async). Основные функции:
- просмотр спортивных матчей (выбор спорта → дата → список матчей → детали матча)
- покупка/получение AI-анализа матча (генерация через LLM)
- учёт пользователей, покупок и баланса (SQLite)
- синхронизация матчей из внешнего API (планировщик)

## Технологии и ключевые зависимости
- `python-telegram-bot` (async handlers, callback_query)
- SQLite (локальная база)
- APScheduler (периодическая синхронизация матчей)
- Внешний источник матчей: TheSportsDB (ключ в env)
- Генерация анализа: OpenAI-совместимый клиент (`AsyncOpenAI`) с `base_url` DeepSeek
- Интеграция пополнений: DonationAlerts (OAuth + listener’ы)

## Точки входа (где запускать/что исполняется)
- `main.py` — основной запуск бота, инициализация, планировщик синка
- `sync_matches.py` — синхронизация матчей в БД
- DonationAlerts:
  - `da_oauth.py` — OAuth/обновление токенов
  - `da_polling.py` / `donationalerts_listener.py` — listener’ы
  - `webhook_server.py` — утилиты/серверная часть для обработки событий/генерации (если используется)

Меню и состояние (инварианты)
Проект использует stateful-навигацию через context.user_data.

Инварианты:
Если используется стек истории (menu_history), то:
переход “вперёд” кладёт в историю текущий реально отображаемый экран
обработчик “Назад” только читает/pop() историю и рендерит, но не пушит новые элементы
Все экраны, зависящие от выбора пользователя, должны иметь достаточно сохранённого состояния в context.user_data
(например: текущий sport/date/match_id и т.д.), чтобы корректно восстановиться при возврате.

Правила изменения кода (очень важно)
Минимальный дифф. Не делай рефакторинг “заодно”, если не просили.
Не меняй форматы callback_data и тексты кнопок/сообщений без явной необходимости.

Для любых правок:
сначала короткий план (файлы/точки изменения/риски),
потом реализация (дифф),
потом проверка (pytest/ручной сценарий).

Если вносишь изменения в БД:
избегай разрушающих миграций без явного запроса
документируй изменения схемы и их обратимость
