Вернул код в рабочее состояние, где добавляются матчи, но нету более подробной статистики.
Основная цель:
Автоматически собирает расписание предстоящих футбольных матчей и сохраняет их в базу данных для последующего использования (например, для спортивного бота).
Ключевые функции:

1. Получение матчей из 5 топ-лиг:
Английская Премьер-лига (Premier League)
Испанская Ла Лига (La Liga)
Немецкая Бундеслига (Bundesliga)
Итальянская Серия А (Serie A)
Французская Лига 1 (Ligue 1)

2. Получение матчей из популярных кубков:
Лига чемпионов УЕФА
Лига Европы УЕФА
Кубок Англии (FA Cup)
Кубок Английской футбольной лиги (EFL Cup)
Кубок Испании (Copa del Rey)

3. Временной диапазон:
Матчи строго на неделю вперед (сегодня + 7 дней)
Все время конвертируется в московское (UTC+3)

4. Использует три метода поиска:
Метод 1: Получение матчей по лигам
Метод 2: Получение матчей по дням
Метод 3: Дополнительный поиск по турам (для АПЛ)

5. Особенности обработки данных:
Удаляет лишние приставки из названий команд (FC, AFC, U19 и т.д.)
Создает уникальные идентификаторы для каждого матча
Удаляет дубликаты матчей
Форматирует информацию о турах ("Premier League. 25 тур")

6. Сохранение в базу данных:
Проверяет наличие дубликатов перед сохранением
Сохраняет структурированные данные:
Команды
Дата и время (в МСК)
Лига/турнир
Стадион
Статус матча
Цена (фиксированная - 150)

7. Ограничения API:
Реализован лимит 28 запросов в минуту
Автоматическая пауза при превышении лимита

8. Режимы работы:
Стандартный: Получение и сохранение в БД
Dry-run: Только просмотр матчей без сохранения
Подробный вывод: Детальная информация о процессе

Выходные данные:
Скрипт выводит в консоль:
Количество найденных матчей
Расписание по дням и лигам
Статистику сохранения (сколько добавлено, пропущено)
