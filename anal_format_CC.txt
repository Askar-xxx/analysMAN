
Задача: создать готовый Node.js проект (файлы, код и инструкции), который реализует pipeline для аналити­ческих таблиц:

1. Принимает структурированный JSON (схема ниже), валидирует его.
2. Подставляет данные в HTML/CSS шаблон (таблица с фиксированной раскладкой столбцов, переносом слов).
3. Рендерит HTML в PNG с помощью Puppeteer (headless Chrome). Кадрировать по блоку `.card`.
4. (Опционально) Отправляет PNG через Telegram Bot API (`sendPhoto`).
5. Генерирует ASCII-fallback (plain text) и сохраняет его.
6. Дать Dockerfile и инструкции запуска локально.

Требования к реализации:
- Код на Node.js (ES modules или CommonJS — можно выбрать ESM). Используй `puppeteer`.
- Шаблонизатор: Handlebars (или маленькая функция подстановки строк).
- HTML шаблон должен использовать `table-layout: fixed;` и `word-wrap: break-word;`. Фиксированные колонки (пример: 28% / 36% / 36%).
- При заполнении ячеек сделать automatic wrap: если текст длиннее — переносить; если очень длинный — усекать с «…» и поле `full_*` сохранять отдельно.
- Валидация JSON: обязательные ключи должны существовать; если какие-то данные отсутствуют — вставлять `—` / `Нет данных`.
- В выводе CI/IDE-friendly: для каждого созданного файла вывести заголовок `=== FILE: <path> ===` и затем содержимое в кодовом блоке. Также выведи краткую инструкцию «Как запустить» (npm install, npm run render, команда для теста).
- В конце выведи тестовый пример: минимальный JSON и результат — имя генерируемого PNG.

Схема входного JSON (обязательная структура — ровно такая; реализация должна поддерживать эту схему):
```json
{
  "title": "Girona — Barcelona, 16 Feb 2026",
  "team_left": "Girona",
  "team_right": "Barcelona",
  "tournament_position": {"left":"#12 — 26 очков после 23 матчей","right":"#1 (зона ЛЧ) — 58 очков после 23 матчей"},
  "current_form": {"left":"D L D W W","right":"L W W W W"},
  "home_away": {"left":"Дома: 8 очков в 5 матчах (2В,2Н,1П)","right":"В гостях: 6 очков в 5 матчах (2В,0Н,3П)"},
  "injuries": {"left":"нет данных","right":"нет данных"},
  "history": ["2024-09-15: Girona 1:4 Barcelona","2024-05-04: Girona 4:2 Barcelona","2023-01-28: Girona 0:1 Barcelona"],
  "stats_trends": {"left":"Забивают в 80% матчей; ср.0.80 гола; пропускают ср.2.60","right":"Забивают в 60% матчей; ср.1.20 гола; пропускают ср.1.20"},
  "metadata": {"generated_at":"2026-02-16T12:34:56Z"}
}
```

Пожелания по качеству:
- Код должен быть комментирован и понятен.
- Обработать ошибки: если JSON невалиден — логировать ошибку и вернуть ASCII-fallback.
- Для CSS дать чёткие классы `.col-1`, `.col-2`, `.col-3` и общую ширину карточки переменной (параметр). Укажи в README, как менять ширину (например `CARD_WIDTH`).
- В обработчике Puppeteer: установить `deviceScaleFactor: 2` для резкости, сделать `clip` на boundingBox `.card` + 10px padding, сделать max width/height guard (не больше 2000px).
- Добавить npm script: `npm run render -- --input example.json --out out.png`. Или эквивалент.

Файлы, которые нужно создать (содержимое обязательно):
- `package.json` с зависимостями (`puppeteer`, `handlebars`, `minimist` (или yargs), `node-fetch` или `axios`).
- `src/render.js` — основной скрипт: читает JSON, валидирует, рендерит HTML (используя `templates/template.hbs`), вызывает Puppeteer, сохраняет PNG.
- `templates/template.hbs` — HTML шаблон, приведенный ниже (с Handlebars placeholders).
- `src/telegram.js` — маленькая функция `sendPhoto(chatId, token, filePath)` (используя `axios` или `node-fetch` и multipart/form-data).
- `example.json` — пример входных данных (как в схеме выше).
- `README.md` — как запустить локально, как запуск в Dockerfile, переменные окружения (BOT_TOKEN, CHAT_ID), рекомендации по production (caching, queue).
- `Dockerfile` — образ с Node.js + puppeteer deps.
- `.gitignore`.
