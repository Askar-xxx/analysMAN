# Изменения проекта — 14 февраля 2026

### Контекст
После миграции на Premium TheSportsDB и реализации табличного формата, пользователь обнаружил, что DeepSeek игнорирует обогащённые данные и генерирует таблицы с заглушками "Нет данных" вместо реальных цифр.

## 🎯 Основные изменения

### 1. Увеличение лимитов символов анализа

**Файлы:** `ANALYSIS_PROMPT.md`, `utils.py`, `test_generation_flow.py`

**Было:**
- Целевая длина: 1400-1900 символов
- Soft cap: 2200 символов

**Стало:**
- Целевая длина: 2200-2800 символов
- Soft cap: 3000 символов
- Hard cap: 3800 символов (без изменений)

**Причина:** Для детальной таблицы с 8 строками и статистикой требуется больше символов.

### 2. Добавлены вспомогательные функции для вычисления статистики

**Файл:** `match_data_fetcher.py`

Добавлены три новые функции перед `build_enriched_context()`:

#### `_calculate_stats_from_form(form_matches: list, is_home: bool) -> dict`
Вычисляет детальную статистику из последних матчей команды:
- `scored_pct`: % матчей где забили
- `conceded_pct`: % матчей где пропустили
- `avg_scored`: среднее голов за матч
- `avg_conceded`: среднее пропущено
- `home_away_form`: форма только дома/выезда (WWDL)
- `home_away_points`: очки в домашних/выездных матчах
- `home_away_record`: статистика В-Н-П

#### `_determine_tournament_zone(rank: int, league: str) -> str`
Определяет зону турнирной таблицы:
- Топ-4 (Premier League, La Liga, Bundesliga, Serie A) → "зона ЛЧ"
- 5-7 место → "зона еврокубков"
- 18+ место → "зона вылета"
- Ligue 1: топ-3 ЛЧ, 19+ вылет

#### `_assess_home_away_quality(points: int, total_matches: int) -> str`
Оценивает качество формы дома/выезда:
- ≥2.0 очка за матч → "Сильная"
- 1.2-2.0 очка → "Средняя"
- <1.2 очка → "Слабая"

### 3. Полная переработка `build_enriched_context()`

**Файл:** `match_data_fetcher.py` (строки 480-630)

Обновлён формат вывода для соответствия табличной структуре:

**Новые секции:**
```
=== ТУРНИРНОЕ ПОЛОЖЕНИЕ ===
[Команда]: #N место (зона ЛЧ/вылета), N очков после N матчей

=== ТЕКУЩАЯ ФОРМА ===
[Команда]: WWDWL

=== ФОРМА ДОМА/НА ВЫЕЗДЕ ===
[Команда] (Сильная дома): N очков в N матчах (XВ,YН,ZП)

=== КЛЮЧЕВЫЕ ИГРОКИ ===
[Команда]: Нет данных  // API не предоставляет

=== СОСТАВЫ ===
[Команда]: Нет данных  // API не предоставляет

=== ИСТОРИЯ ЛИЧНЫХ ВСТРЕЧ ===
Последние N матчей:
YYYY-MM-DD: Команда A X:Y Команда B

=== СТАТИСТИЧЕСКИЕ ТРЕНДЫ ===
[Команда]:
  • Забивают в N% матчей
  • Пропускают в N% домашних/выездных игр
  • В среднем N.NN гола за матч
  • Пропускают в среднем N.NN гола
```

**Результат:** enriched_context содержит ~900-1000 символов структурированных данных.

#### Обновлены инструкции по заполнению:

- `=== ТЕКУЩАЯ ФОРМА ===`

**ИСПОЛЬЗУЙ ЭТИ ДАННЫЕ** для заполнения таблицы!

**Добавлен пример правильного заполнения** — показывает как переносить данные из секций === в ячейки таблицы.

### 5. Исправление промпта в ai_generator.py

**Файл:** `ai_generator.py` (строки 400-413)

**Проблема:** DeepSeek видел enriched_context с данными, но копировал плейсхолдеры `[позиция (зона), очки]` из шаблона вместо заполнения реальными данными.

**Решение:** Обновлён промпт с явными инструкциями:

```python
prompt = f"""Напиши компактный аналитический обзор предстоящего матча.

Данные матча:
{basic_info_str}

ОБОГАЩЁННЫЕ ДАННЫЕ (ИСПОЛЬЗУЙ ИХ ДЛЯ ЗАПОЛНЕНИЯ ТАБЛИЦЫ):
{enriched_context}

ИНСТРУКЦИИ ПО ФОРМАТУ:
{ANALYSIS_PROMPT_TEMPLATE}

ВАЖНО: Используй данные из секций === выше === для заполнения таблицы!
НЕ копируй плейсхолдеры типа "[позиция (зона), очки]" — замени их на РЕАЛЬНЫЕ данные из секций!
Замени "команда A" на {team1}, "команда B" на {team2}."""
```

**Результат:** DeepSeek теперь корректно использует данные из enriched_context.

### 6. Исправление ошибки sqlite3.Row

**Файл:** `user_handlers.py` (строки 342-346, 361)

**Проблема:**
```
AttributeError: 'sqlite3.Row' object has no attribute 'get'
```

`match_data_fetcher.py` использовал `match.get('team1')`, но из БД приходит `sqlite3.Row`, у которого нет метода `.get()`.

**Решение:** Добавлена конвертация в dict перед вызовом fetcher:

```python
# Конвертируем sqlite3.Row в dict для совместимости
match_dict = dict(match) if not isinstance(match, dict) else match
enriched_data = fetcher.fetch_match_data(match_dict)
enriched_context = build_enriched_context(match_dict, enriched_data)
...
analysis_text = await generate_match_analysis_with_context(match_dict, enriched_context)
```
