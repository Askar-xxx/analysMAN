================================================================================
1. ПЕРВЫЙ ЗАПУСК (новый разработчик)
================================================================================

Шаг 1 — Клонировать репозиторий
--------------------------------
  git clone https://github.com/Askar-xxx/analysMAN.git
  cd analysMAN

Шаг 2 — Создать виртуальное окружение и установить зависимости
---------------------------------------------------------------
  python -m venv venv

  Windows:
    venv\Scripts\activate

  Mac/Linux:
    source venv/bin/activate

  pip install -r requirements.txt

Шаг 3 — Создать файл с секретами
----------------------------------
  Скопировать .env.example в .env:
    cp .env.example .env   (Mac/Linux)
    copy .env.example .env  (Windows)

  Открыть .env и заполнить реальными значениями:
    TELEGRAM_TOKEN        — токен бота от @BotFather
    DEEPSEEK_API_KEY      — ключ DeepSeek API
    THESPORTSDB_KEY       — ключ TheSportsDB Premium
    DA_CLIENT_ID          — DonationAlerts Client ID
    DA_CLIENT_SECRET      — DonationAlerts Client Secret
    DA_ACCESS_TOKEN       — получается через da_oauth.py (см. раздел 5)
    DA_PROFILE_URL        — ссылка на страницу донатов
    ANALYSIS_PRICE_RUB    — цена анализа (сейчас 1 для теста)
    MAIN_ADMIN_ID         — твой Telegram ID
    SUPPORT_USERNAME      — юзернейм поддержки

Шаг 4 — Запустить бота локально
---------------------------------
  Терминал 1 (бот):
    python main.py

  Терминал 2 (слушатель донатов):
    python da_polling.py

  Бот готов — открывай Telegram и пиши /start


================================================================================
2. ЕЖЕДНЕВНАЯ РАБОТА
================================================================================

Перед началом работы — синхронизироваться с репозиторием:
  git pull origin main

Работа с кодом:
  - Редактируй файлы
  - Тестируй локально (python main.py)
  - Проверяй линтинг: flake8 . --max-line-length=120
  - Запускай тесты: python -m pytest tests/ -v

Важные файлы проекта:
  main.py                — точка входа, запуск бота
  user_handlers.py       — обработчики кнопок и команд пользователей
  admin_commands.py      — /stats, /clean_matches, /clean_all_matches
  ai_generator.py        — генерация анализов через DeepSeek
  database.py            — работа с SQLite базой данных
  sync_matches.py        — синхронизация матчей из TheSportsDB
  da_polling.py          — слушатель донатов DonationAlerts
  keyboards.py           — кнопки интерфейса
  ANALYSIS_PROMPT.md     — промпт для AI (редактировать здесь)
  config.py              — конфигурация (читает из .env, не трогать)


================================================================================
3. КАК ЗАДЕПЛОИТЬ ИЗМЕНЕНИЯ
================================================================================

Всё происходит автоматически через GitHub Actions.

Шаг 1 — Закоммитить изменения
-------------------------------
  git add .
  git commit -m "feat: описание что сделано"
  git push origin main

Шаг 2 — GitHub Actions сделает всё сам
----------------------------------------
  Автоматически запустится:
    1. Линтинг кода (flake8)
    2. Запуск тестов (pytest)
    3. Сборка Docker образа
    4. Загрузка на Docker Hub
    5. Деплой на сервер (Нидерланды, 72.56.119.31)

  Посмотреть статус: https://github.com/Askar-xxx/analysMAN/actions

  Зелёный — деплой прошёл успешно.
  Красный — посмотри логи, исправь ошибку и запушь снова.

ВАЖНО: Если тесты или линтинг упали — деплой НЕ произойдёт.
Сначала исправь ошибки, потом пуш.

Время полного деплоя: около 3-5 минут.


================================================================================
4. УПРАВЛЕНИЕ БОТОМ НА СЕРВЕРЕ
================================================================================

Подключение к серверу:
  ssh root@72.56.119.31

Статус бота (запущен или нет):
  docker compose -f ~/sports-bot/docker-compose.yml ps

Логи в реальном времени (Ctrl+C для выхода):
  docker compose -f ~/sports-bot/docker-compose.yml logs -f

Последние 100 строк логов:
  docker compose -f ~/sports-bot/docker-compose.yml logs --tail=100

Перезапустить бота:
  docker compose -f ~/sports-bot/docker-compose.yml restart

Остановить бота:
  docker compose -f ~/sports-bot/docker-compose.yml down

Запустить бота вручную (если остановлен):
  cd ~/sports-bot && docker compose up -d

Обновить вручную без CI/CD (крайний случай):
  cd ~/sports-bot
  docker compose pull
  docker compose up -d --remove-orphans


================================================================================
5. ОБНОВЛЕНИЕ ТОКЕНОВ DONATIONALERTS
================================================================================

Токены живут примерно 1 год. Когда истекут — бот перестанет получать донаты.

Шаг 1 — Запустить OAuth локально (на своём компьютере):
  python da_oauth.py

  Откроется браузер → нажать "Разрешить" → вернуться в терминал.
  Новые токены автоматически запишутся в файл .env

Шаг 2 — Обновить токены на сервере:
  ssh root@72.56.119.31
  nano ~/sports-bot/.env

  Найти строки DA_ACCESS_TOKEN и DA_REFRESH_TOKEN,
  заменить на новые значения из локального .env.
  Сохранить: Ctrl+O → Enter → Ctrl+X

Шаг 3 — Перезапустить бота с новыми токенами:
  docker compose -f ~/sports-bot/docker-compose.yml up -d --force-recreate

6. ЕСЛИ ЧТО-ТО СЛОМАЛОСЬ
================================================================================

Бот не отвечает в Telegram:
  1. Проверить статус: docker compose -f ~/sports-bot/docker-compose.yml ps
  2. Смотреть логи: docker compose -f ~/sports-bot/docker-compose.yml logs --tail=50
  3. Перезапустить: docker compose -f ~/sports-bot/docker-compose.yml restart

CI/CD не деплоит (красный в Actions):
  1. Открыть GitHub Actions → кликнуть на упавший run
  2. Посмотреть в каком шаге ошибка
  3. Исправить код и запушить снова

Деплой прошёл, но бот не обновился:
  На сервере:
    cd ~/sports-bot
    docker compose pull
    docker compose up -d --remove-orphans

Бот крашится сразу после запуска:
  Проверить .env — скорее всего пустое или неверное значение переменной.
  docker compose -f ~/sports-bot/docker-compose.yml logs --tail=20

Матчи не синхронизируются:
  Проверить THESPORTSDB_KEY в .env — ключ должен быть от Premium аккаунта ($9/мес).

Донаты не засчитываются:
  1. Проверить что DA_ACCESS_TOKEN актуален (см. раздел 5)
  2. Проверить что da_polling.py запущен внутри контейнера (см. логи)
