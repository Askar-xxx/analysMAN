# Админские команды

Документация по администрированию Telegram бота analysMAN.

## Доступ

Команды доступны только пользователям из таблицы `admins` в БД.

Добавить админа через SQLite:
```bash
sqlite3 sports_bot.db
INSERT INTO admins (user_id) VALUES (123456789);  -- ваш Telegram ID
.exit
```

## Команды

### `/stats` - Статистика базы данных

Показывает текущее состояние БД:
- Количество матчей (всего, с анализом, с PNG)
- Количество покупок (всего, оплачено, ожидает)
- Количество пользователей
- Размер PNG кэша

**Пример вывода:**
```
📊 Статистика базы данных:

🏆 Матчи: 45
  ├─ С анализом: 12
  └─ С PNG: 12

💳 Покупки: 15
  ├─ Оплачено: 12
  └─ Ожидает: 3

👥 Пользователи: 8

💾 Кэш PNG: 12 файлов (3.45 MB)
```

### `/clean_matches` - Безопасная очистка старых данных

Удаляет:
- ✅ Старые покупки (>1 день после матча)
- ✅ Старые матчи без покупок (>1 день)
- ✅ Соответствующие PNG файлы анализов
- ✅ Осиротевшие PNG файлы (есть в папке, но нет в БД)

**Безопасность:**
- НЕ удаляет матчи с оплаченными покупками
- НЕ удаляет актуальные матчи
- НЕ влияет на работу бота

**Использование:** Рекомендуется выполнять раз в неделю для очистки старых данных.

**Пример вывода:**
```
✅ Очистка завершена:

🗑 Удалено покупок: 8
🗑 Удалено матчей: 15
🗑 Удалено осиротевших PNG: 2
```

### `/clean_all_matches CONFIRM` - ПОЛНАЯ очистка (⚠️ ОПАСНО!)

**ВНИМАНИЕ:** Удаляет ВСЁ из БД, включая оплаченные покупки!

Удаляет:
- ❌ ВСЕ покупки (paid и pending)
- ❌ ВСЕ матчи
- ❌ ВСЕ PNG файлы анализов
- ♻️ Сбрасывает счётчики ID (начинаются с 1)

**Использование:** Только для тестирования или полной переустановки бота.
Требует явного подтверждения аргументом `CONFIRM`.

**Пример вывода:**
```
✅ ПОЛНАЯ очистка завершена:

🗑 Удалено покупок: 25
🗑 Удалено матчей: 50
🗑 Удалено PNG файлов: 25

♻️ Счётчики ID сброшены
```

## Автоматическая очистка

Бот автоматически очищает данные через APScheduler:

**Расписание:** При старте бота + каждые 6 часов (или 1 минута в тестовом режиме)

**Что очищается:**
1. Старые покупки (>1 день после матча) → удаляет PNG
2. Старые матчи без покупок (>1 день) → удаляет PNG
3. Деактивированные матчи без покупок → удаляет PNG

**Логирование:**
```
[10:00:00] APScheduler: ЗАПУСК синхронизации...
Шаг 1/3: Синхронизация новых матчей...
Найдено: 15, Добавлено: 3, Пропущено: 12
Шаг 2/3: Удаление старых матчей...
Удалено старых матчей: 5
Удалено PNG файлов (без покупок): 5
Шаг 3/3: Очистка старых покупок...
Удалено старых покупок: 8
Удалено PNG файлов: 8
[10:00:15] APScheduler: синхронизация ЗАВЕРШЕНА
```

## PNG кэш

**Расположение:** `analysis_cache/analysis_{match_id}.png`

**Автоудаление:**
- При удалении старых покупок (>1 день после матча)
- При удалении матчей без покупок
- При выполнении `/clean_matches` или `/clean_all_matches`

**Ручное удаление:**
```bash
# Удалить все PNG файлы
rm -rf analysis_cache/*.png

# Или через Python
python -c "import shutil; shutil.rmtree('analysis_cache', ignore_errors=True)"
```

## Troubleshooting

### Команды не работают
- Проверьте, что ваш Telegram ID добавлен в таблицу `admins`
- Проверьте логи бота на ошибки

### PNG файлы не удаляются
- Проверьте права доступа к папке `analysis_cache/`
- Проверьте логи: `logger.warning("Не удалось удалить PNG...")`

### База данных переполнена
1. Выполните `/stats` для оценки размера
2. Выполните `/clean_matches` для очистки старых данных
3. Если нужно — `/clean_all_matches` (осторожно!)

## Мониторинг

**Рекомендуемая частота проверок:**
- `/stats` — каждый день
- `/clean_matches` — раз в неделю (если автоочистка отключена)

**Критические метрики:**
- Размер PNG кэша > 100 MB → выполнить `/clean_matches`
- Pending покупок > 50 → проверить listener (может не работать)
- Матчей без анализа > 20 → проверить DeepSeek API или listener
