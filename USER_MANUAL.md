analysMAN (название временное) - Руководство для пользования

Что это вообще?

Telegram-бот, который продаёт AI-анализы спортивных матчей. Матчи загружаются из TheSportsDB API (временное решение), анализы генерирует нейросеть (DeepSeek).

---

Быстрый старт (5 минут)

1. Установка
pip install -r requirements.txt

2. Настройка
Откройте файл config.py через блокнон и впишите:
- TOKEN — токен Telegram-бота 
- DEEPSEEK_API_KEY — ключ от DeepSeek API (решение временное)

3. Загрузка матчей
Загрузить матчи из топ-лиг + добавить статистику (H2H, таблица)
python sync_matches.py --mode all --enrich

Эта команда:
- Скачает ближайшие матчи из 5 топ-лиг (АПЛ, Ла Лига, Серия А, Бундеслига, Лига 1) + 5 кубков
- Добавит историю личных встреч (H2H) — последние 5-7 матчей
- Добавит данные из турнирной таблицы — позиция, очки, форма (WWDWL)

4. Запуск бота
python main.py

---

Команды sync_matches.py
Это главный скрипт для загрузки матчей. Вот все варианты запуска:

Основные команды
* Рекомендуемая команда — все матчи + статистика
python sync_matches.py --mode all --enrich

* Быстрая проверка — только 3 матча
python sync_matches.py

* Только 3 матча + статистика
python sync_matches.py --enrich

* Посмотреть что загрузится (без записи в базу)
python sync_matches.py --mode all --dry-run

Все флаги

|-------------------|----------------------------------------------------------------------|
|      Флаг         |                              Что делает                              | 
|-------------------|----------------------------------------------------------------------|
|  --mode all       | Загружает все матчи из 10 лиг/кубков (по умолчанию: только 3 матча)  |
|  --enrich         | Добавляет H2H и турнирную таблицу к каждому матчу                    | 
|  --limit N        | Загружает N матчей вместо 3 (только в режиме top3)                   |
|  --dry-run        | Только показать матчи, не сохранять в базу                           |
|  --cache-teams    | После загрузки — кэшировать данные команд                            |
|  --verbose        | Подробный вывод                                                      |
|-------------------|----------------------------------------------------------------------|

Примеры

* Загрузить 5 ближайших матчей + статистика
python sync_matches.py --limit 5 --enrich

* Загрузить всё, но сначала посмотреть
python sync_matches.py --mode all --dry-run

* Загрузить всё + статистика (полный вариант)
python sync_matches.py --mode all --enrich

*Загрузить 7 матчей (режим top3), статистика, кеширование данные команд и подобный вывод
python sync_matches.py --limit 7 --enrich --cache-teams --verbose

Что такое --enrich и зачем это нужно?

Без --enrich бот знает о матче только базовую информацию: кто играет, когда, в какой лиге. Анализы получаются абстрактными и неполными.
С --enrich бот загружает дополнительные данные:


* H2H (head-to-head, то есть история личных встреч)
Последние 5-7 матчей между командами с реальными датами и счетами.

Пример в анализе:
Последние 5 встреч (TheSportsDB):
• 2024-02-28: Chelsea 3-2 Leeds
• 2023-03-04: Chelsea 1-0 Leeds
• 2021-12-11: Chelsea 3-2 Leeds
Баланс: 3W-0D-0L (Chelsea)


*Standings (турнирная таблица)
Позиция команды в лиге, очки, форма (последние 5 матчей), разница мячей.

Пример в анализе:
Cardiff City уверенно возглавляет таблицу с 63 очками.
Форма в последних 5 матчах: WDWDW (3 победы, 2 ничьи) —
стабильная и результативная игра. Разница мячей: +26.


*Ограничения
- Турнирная таблица: бесплатный API возвращает только ТОП-5 команд лиги. Если команда не в топ-5 — данных о её позиции не будет.
- Статистика игроков: недоступна в бесплатном TheSportsDB API.
- История личных встреч: работает для всех команд без ограничений.

## Структура базы данных

|   Таблица   |                          Что хранит                            |
|-------------|----------------------------------------------------------------|
| matches     | Матчи: команды, дата, лига, стадион, анализ, H2H, тур. таблица |
| users       | Пользователи: telegram_id, баланс, количество покупок          |
| purchases   | Покупки: кто какой анализ купил                                |
| admins      | Список администраторов                                         |
| teams       | Кэш данных команд (опционально)                                |
| sync_meta   | Время последней синхронизации                                  |

API (TheSportsDB)

Текущий ключ: 3 (бесплатный, для разработки)

Лимиты:
- 25-30 запросов в минуту
- При превышении — скрипт автоматически ждёт и повторяет
- тур. таблица: только топ-5 команд лиги
- H2H: полные данные (20+ матчей)

НЕ СПОЛЬЗОВАТЬ ключ 123 — он ограничен 2 результатами для H2H.

## Частые вопросы

*Матчей на сегодня: 0 — что делать?
Проверьте дату. Матчи загружаются на ближайшие дни. Если сегодня нет игр — значит их реально нет

*Анализ пустой — почему?
Анализы генерируются при покупке через бота (или вручную). Пустое поле значит что анализ ещё не запрошен.

*Скрипт долго работает с --enrich в чем проблема?
Это ок. На каждый матч делается 2 дополнительных запроса к API с паузой 2.5 секунды (защита от бана). 20 матчей ≈ 2 минуты.

*Ошибка HTTP 429 в терминале
Превышен лимит запросов. Скрипт сам подождёт и повторит. Если ошибка повторяется — подожди ≈ 1 минуту.

*Дубликаты матчей
Не могут создаваться по умолчанию. Скрипт проверяет идентификационный номер события (api_event_id) и пропускает существующие.
